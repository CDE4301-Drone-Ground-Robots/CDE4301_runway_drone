# Team portraits

The current portraits are Charan.png, Arun.png, and Talitha.jpg. Filenames are matched without regard to case, and their exact casing is preserved in site URLs for GitHub Pages. To replace them, use either:

- The latest combined portrait image as portraits.png (also accepts .jpg, .jpeg, or .webp). Keep the full original canvas and photo positions; it is automatically cropped into the three cards.
- Individual photographs named charan.png, arun.png, and talitha.png (also accepts .jpg, .jpeg, or .webp). Individual files take priority over the combined image.

Rebuild with npm run docs:build and restart the preview after adding files. The development server watches this directory. Portraits are loaded only when present, so pending images cause no broken requests.

Names, roles and Semester 1 contribution descriptions were transcribed from the user's team-card reference. The combined portrait crop uses normalized positions from the 2048 x 579 displayed reference and scales with the original 2407 x 681 image.
