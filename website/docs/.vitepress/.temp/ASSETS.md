# NUS logo

The NUS header logo is stored locally at docs/public/nus-logo.png. Source: https://github.com/theflyingwolves/NUS-Slides-Latex-Template/blob/master/nus-logo.png

The university mark remains the property of the National University of Singapore. It is displayed alongside AIS-407 as requested. FOD ARGUS remains the drone name in the overview and page metadata.
The runway-night.svg hero background is an original vector illustration of a runway at night, created for this website.


## Photorealistic hero backdrop

runway-night-photo.png is an AI-generated photorealistic night runway created for this website. It is decorative artwork, not a photograph documenting a particular airport or a project test site. It contains no aircraft, so the actual UAV render can be overlaid separately. The earlier runway-night.svg is retained as an unused original illustration. Stock-photo candidates were not integrated into the website.

FOD_Argus.glb is the user's SolidWorks export. Draco decoder binaries are distributed with Three.js and originate from Google Draco (Apache 2.0); see https://github.com/google/draco. The GLB is not modified by this website.
