04 / Reproducibility

What these numbers mean

Definitions first, then the exact counts and model assumptions.

MACs / GMACs

A multiply-accumulate combines multiplication and addition. One GMAC means one billion MACs.

FLOPs / GFLOPs

Floating-point arithmetic operations. One GFLOP means one billion operations. Here, 1 MAC = 2 FLOPs.

Parameters

Weight and bias values stored in the model. Parameter count is independent of image resolution and excludes feature buffers.

ROI / letterbox

ROI means a cropped region of interest. Letterboxing resizes while preserving aspect ratio, then pads to the required shape.

Arithmetic checked independently. PyTorch operator-level convolution and matrix-product counts matched the four model profiles at the listed resolutions. Weight totals also matched. This validates the stated arithmetic scope; unknown YOLO source shapes and search-backend behavior remain explicit assumptions.
Counting convention and exclusions

1 MAC = 2 FLOPs; G = 10⁹; M = 10⁶; MiB = 2²⁰ bytes. Convolution, linear layers and YOLO attention matrix products are included. Normalization, activations, pooling, interpolation, residual/scalar arithmetic, preprocessing, NMS and output processing are excluded. Counts describe dominant dense arithmetic, not every operation. FLOPs here is an operation count per invocation, not FLOPs per second (FLOP/s). Parameters are counted independently from model.parameters(); buffers are excluded. No whole-pipeline latency or FPS is claimed.

Construction and profiling method

Actual local Ultralytics checkpoints are loaded. Crack weights strictly match segmentation_models_pytorch.Unet with ResNet34, decoder channels (256, 128, 64, 32, 16), three input channels and one output class. PatchCore strictly loads a timm Wide-ResNet50-2 feature extractor with layer2/layer3 outputs; unused layer4 and the classification head are absent. THOP 2.1.6 uses explicit convolution/linear rules plus separate functional-attention counting. All models are forwarded at full input size.
